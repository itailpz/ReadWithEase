# ReadWithEase
An Arduino-based assistive reading device designed to convert text into speech using Python, OCR, and 3D-printed parts.
My goal is to explore how reading can be made more accessible with technology while developing my engineering skills.
## Problem Statement
Reading printed text can be challenging for individuals with visual impairments or reading difficulties. This project explores how engineering and technology can help make printed information more accessible.

## Project Objective
My goal is to design and develop a portable assistive reading device that can recognize printed text and convert it into spoken audio.

## Technologies
- Arduino Mega 2560
- Python
- Optical Character Recognition (OCR)
- Computer-Aided Design (CAD)
- 3D Printing
- Electronics and Circuit Design

## Engineering Design Process
1. Research existing assistive reading technologies.
2. Design the initial hardware and software.
3. Develop and test the first prototype.
4. Create a custom 3D-printed enclosure.
5. Evaluate performance and identify improvements.
6. Refine the final design.
